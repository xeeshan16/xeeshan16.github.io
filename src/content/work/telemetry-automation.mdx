## Context

Operational signals were spread across systems, and engineers assembled the picture by hand for every incident.

## Approach

- FastAPI services that ingest and analyse operational telemetry.
- Kafka consumers that react to known event patterns and trigger automated steps, so routine work doesn't wait for a person.

## Production story

### Rebuilding the same picture by hand on every incident

**What happened.** Operational signals were spread across systems. Every incident started the same way: the on-call engineer pulled signals together by hand before they could start fixing anything, and routine issues with well-known causes still waited for a person to notice and act.

**The fix.** I split the work into two flows on the same Kafka stream:

- **Known patterns are automated.** Kafka consumers watch for event patterns with known responses and trigger the automated step directly, so routine work doesn't wait for a person.
- **Everything else arrives pre-assembled.** FastAPI services ingest and analyse the telemetry, so when an engineer is needed they start from an analysed picture instead of a blank page.
